Linux System Monitor

A Linux System Monitor developed in C to monitor system performance and resource utilization in real time. The application retrieves information such as CPU usage, memory usage, disk usage, and running processes using Linux system files and system calls.

Features

- CPU Usage Monitoring
- Memory Usage Monitoring
- Disk Usage Information
- Process Monitoring
- Real-Time System Statistics
- Terminal-Based Interface

Technologies Used

- C Programming
- Linux Operating System
- GCC Compiler
- Linux "/proc" File System

Usage

Compile and run the program on a Linux system to view real-time system information and performance metrics.

Learning Outcomes

- Understanding Linux system architecture
- Working with system calls and the "/proc" filesystem
- Resource monitoring and performance analysis
- Developing system-level applications in C
